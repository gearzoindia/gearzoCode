# GearZo Customer App Assets

Place the following brand assets in this folder before building standalone binaries:
- `icon.png`: App icon (1024x1024 px PNG)
- `splash.png`: Splash screen image with GearZo green background (#1B5E20)
- `adaptive-icon.png`: Android adaptive icon foreground (1024x1024 px PNG)
- `favicon.png`: Web favicon (48x48 px PNG)
